Un exemple concret

Récupérer les données d'un poste verrouillé.

Un poste client était verrouillé et ses données devaient être récupérées. L'accès s'est fait en ligne de commande : lister les dossiers du profil, puis les copier vers un dossier de récupération, en mode sauvegarde et sans s'arrêter sur les fichiers en erreur.

Ce cas montre aussi pourquoi les droits d'accès et le chiffrement des disques comptent : un accès physique à une machine suffit parfois à lire ses fichiers.

recuperation.cmd
rem lister le profil, fichiers cachés compris
dir /a D:\Users\<profil>

rem copier en mode sauvegarde, sans retenter les erreurs
robocopy D:\Users\<profil> C:\Recup /E /B /R:0 /W:0

rem ouvrir le dossier de récupération
explorer C:\Recup
acces_distant.cmd
rem adresse interne du serveur, à cibler dans la redirection
ipconfig

rem vérifier que le serveur SQL écoute bien sur son port
netstat -an | findstr :3306

rem tester l'accès depuis l'extérieur, vers l'IP publique
powershell Test-NetConnection <ip_publique> -Port 3306
Un autre exemple

Se connecter à AKEAD depuis l'extérieur.

Le port SQL interne est le 3306. Pour qu'un PC situé hors du réseau du client puisse se connecter à AKEAD, on crée une redirection de ports sur la box : le port est ouvert depuis l'extérieur et renvoyé vers le serveur concerné.

C'est aussi un point de vigilance : un port SQL ouvert sur Internet est une porte d'entrée vers les données. Il faut savoir pourquoi on l'ouvre, et pour qui.

Une astuce utile

Installer Windows sans connexion Internet imposée.

À l'écran de choix du wifi, Maj + F10 ouvre une invite de commandes, et la commande oobe\bypassnro permet de continuer sans connecter le PC à Internet. Les mises à jour se font ensuite une fois le poste prêt.

installation_windows.cmd
rem à l'écran de choix du wifi : Maj + F10 ouvre l'invite
oobe\bypassnro

rem le poste redémarre et propose de continuer sans Internet
